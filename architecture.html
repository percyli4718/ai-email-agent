📧 AI Agent 邮件处理系统架构

药品分销询盘场景 · 三层 AI 架构 · Agent 合同制

📥 非结构化输入

客户邮件 (英文/葡萄牙文/中文)
附件：PDF 合同、产品规格书

Layer 1: 分类路由

🔍 分类器 (Sonnet)

• 邮件类型识别
• 优先级评分
• 语言检测
• 路由决策

📊 路由决策

• 询盘 → Layer 2
• 投诉 → 人工
• 常规 → 自动回复

Layer 2: 上下文检索

🔗 向量检索

• ChromaDB 相似邮件
• 客户历史对话
• 产品知识库

📚 Wiki-Link 回溯

• 合同条款关联
• 价格政策引用
• 合规性检查

Layer 3: 分析生成

🤖 智能路由

• 80% Sonnet(成本)
• 20% Opus(复杂)
• 动态选择

📝 结构化输出

• 提取：产品/数量/目的地
• 生成：报价单 JSON
• 草稿：回复邮件

✅ 业务动作

• 写入 CRM
• 发送报价邮件
• 触发合同 Agent

📋 Agent 合同制执行流程

1️⃣ CEO Agent 分解目标

接收询盘 → 解析为依赖图
识别所需子 Agent 类型

依赖图生成

2️⃣ 子 Agent 沙箱执行

• 价格 Agent: 查询价格库
• 合规 Agent: 检查出口许可
• 物流 Agent: 计算运费

预算硬 Kill 写隔离

3️⃣ CEO 评审交付物

• Promote: 批准并执行
• Redelegate: 重新分配
• Reject: 拒绝并记录

评审决策

4️⃣ Prompt 进化优化

用历史邮件作为 Ground Truth
自动变异 prompt → 对比评估 → 保留/丢弃

Karpathy 模式

Layer 2: 上下文检索 (紫色)
Layer 3: 分析生成 (橙色)
